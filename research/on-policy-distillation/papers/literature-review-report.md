OPD Literature Review (March 2025 – March 2026)
1. Papers We Were Missing
MiniLLM (Gu et al., 2024). “MiniLLM: On-Policy Distillation of Large Language Models.” ICLR 2024. This concurrent work to GKD proposes training a small student via policy-gradient on a reverse-KL objective with respect to the teacher’s distribution. The student is sampled on-policy and updated to “avoid learning many long-tail variants,” focusing on the teacher’s modes[1]. They introduce tricks like teacher-mixed sampling, single-step regularization and length-normalized rewards. Experiments (instruction-following tasks) show more precise, less biased answers than off-policy KD. Relation: Similar in spirit to GKD but explicitly uses reverse KL via policy gradients. It confirms that on-policy reverse-KL distillation can outperform standard (forward-KL) KD. Likely warrants a detailed note as a complementary approach. (Code: Microsoft; implements on-policy PG with HuggingFace LLMs.)
ImitKD (Lin & Xia, 2020). “Autoregressive Knowledge Distillation through Imitation Learning.” EMNLP 2020. The student is trained on teacher-generated outputs by treating distillation as an imitation learning problem. This addresses exposure bias by having the student learn from its own sampled prefixes (rolled out by the teacher as oracle). On machine translation and summarization, ImitKD yields +1.4–4.8 BLEU/ROUGE over training from scratch, with up to 14× faster inference[2]. Relation: It predates OPD but embodies the idea of “student learns from trajectories” and was used as an off-policy/on-policy mixed baseline in GKD. Serves as a conceptual ancestor (exposes issues of distribution mismatch) and a robust baseline. (Code: ASAPPresearch/imitkd on GitHub.)
Context Distillation (Snell et al., 2022). “Learning by Distilling Context.” NeurIPS 2022. Introduces the idea of “privileged context” distillation: the model first solves tasks given extra context (instructions or chain-of-thought) and then is fine-tuned to answer without that context. Specifically, the model generates a scratchpad+answer with instructions present, then is trained to predict the same answer from the question alone[3]. This internalizes reasoning and instructions in the model parameters. Relation: A key precursor to self-distillation and OPSD: it shows a model can internalize privileged info (instructions, CoT). Context-distillation is essentially off-line “self-distillation,” complementary to OPD. (No released code.)
Qwen3 Technical Report (2025). “Qwen3: A System Report.” arXiv 2505.09388. Internal report by Qwen team showing that on-policy distillation can replicate large-RL performance at far lower cost. For example, a 7B model trained with OPD matched a strong model’s score (74.4% on AIME’24) using ~10× less compute than RL (as later replicated by Lu’s blog)[4]. Relation: Provides real-world evidence that OPD (KL-based distillation) can effectively replace RL on reasoning benchmarks. It overlaps with OPD theory and claims 10× cost savings. (Note: RL training steps were 170 vs ~10 for distillation.) Likely useful for practical context; no public code.
Thinking Machines Blog (Lu, 2025). “On-Policy Distillation” (blog post). A detailed walkthrough of implementing reverse-KL OPD in practice, using the Tinker framework. Claims on-policy distillation learns teacher policies 7–10× faster (50–100× compute savings) over RL[5]. It replicates Qwen3’s results (e.g. AIME’24), reaching the teacher’s score in ~10 steps vs 70 for RL[5]. The blog stresses reverse-KL and memory efficiency. Relation: It concretely validates the compute-efficiency claims of OPD (over Agarwal/Gu theory papers). It is more of an engineering report than a new method, but it synthesizes GKD and MiniLLM ideas. (No new method; code on Tinker/HuggingFace.) Medium priority: useful practical insights on implementation.
POPE (Qu et al., 2026). “POPE: Learning to Reason on Hard Problems via Privileged On-Policy Exploration.” This RL method uses privileged oracle solutions during training. For very hard problems, POPE prefixes the prompt with partial oracles so that RL rollouts get non-zero reward. After training, the model can solve the original tasks without hints. Formally, “privileged on-policy exploration” augments difficult instances with oracle solution prefixes, yielding training signals that transfer back to the original environment[6]. It substantially expands the set of solvable problems. Relation: Less of a distillation method and more like “hindsight hints.” Still, it relates to OPD in using privileged information (oracle solutions) to guide learning. It contrasts with KD approaches by injecting hints into rollouts rather than matching distributions. Worth noting as an alternative privileged-info approach; moderate priority. (No known code; described on arXiv.)
Nudging (Chen et al., 2025). “Nudging the Boundaries of LLM Reasoning” (ICLR 2026). Introduces NuRL, an RL-like method that injects self-generated hints for zero-reward problems. When a student fails all rollouts on a problem, the model first generates a hint (abstract reasoning cue) given the gold answer, then re-runs rollouts with this hint. This “nudging” boosts pass rates from 0→nonzero, enabling learning on previously “unsolvable” samples[7]. Self-generated hints avoid distribution shift. NuRL significantly raises the model’s performance ceiling compared to standard RL[7]. Relation: An alternative strategy for dealing with sparse-reward tasks. It doesn’t use a separate teacher model for distillation, but it does leverage privileged information (hints) on-policy. It’s cited as a dense-signal baseline (e.g. in RLTF). Low-to-medium priority (RL focus, no code released).
Feedback Descent (Lee et al., 2025). “Feedback Descent: Open-Ended Text Optimization via Pairwise Comparison.” Proposes optimizing text (prompts, code, molecules) through structured textual feedback rather than scalar rewards. An LLM (evaluator) provides pairwise preferences with accompanying textual rationale, and the student uses these critiques via in-context learning to iteratively improve outputs. Crucially, this is done at inference time (editing the prompt/text), with no weight updates, widening the information bottleneck. Feedback Descent outperforms GRPO/REINVENT on prompt/code/molecule tasks[8]. Relation: Used as a baseline in RLTF as a dense credit-assignment method. It is not a weight-space distillation, but is relevant as a “text-space OPD” baseline. Useful to mention as part of the landscape. (Code: Likely on author repos.)
Variational Reasoning (Zhou et al., 2025). “Variational Reasoning for Language Models.” Frames chain-of-thought (CoT) reasoning as latent variables in a variational inference (VI) framework. They derive an ELBO on the log-likelihood of correct answers by marginalizing over traces, introduce multi-trace IWAE-style objectives for tighter bounds, and use a forward-KL loss to stabilize training. Importantly, they show that RL and rejection-based methods can be viewed as local forward-KL objectives under this framework. This yields a principled joint optimization of a separate variational posterior (to sample good reasoning traces) and the main model[9]. Relation: Conceptually close to pi-Distill: both use an auxiliary model to propose reasoning paths and alternate updating. Unlike OPD, it maximizes answer likelihood via ELBO rather than a KL loss, and assumes access to oracle answers to define the posterior. Worth noting for its probabilistic perspective. (Code: Not publicly noted.)
Learning Beyond Teacher (Yang et al., 2026). “Generalized On-Policy Distillation with Reward Extrapolation.” Formalizes OPD as a special case of KL-constrained RL and then generalizes it. They introduce G-OPD: it allows tuning the weight of the reward (derived from teacher KL) relative to the KL penalty by introducing a scaling factor. With scaling >1 (ExOPD), the student can extrapolate beyond the teacher, even merging multiple teachers’ knowledge to surpass all. In experiments on math/code, ExOPD consistently beats standard OPD (and can exceed the teacher’s score)[10]. They also propose “reward correction” by comparing to the teacher’s base model. Relation: Extends OPD by showing the teacher need not be an upper bound. It complements the core OPD methods by adding flexibility. (No code link; conceptual.)
2. New Papers Discovered
Ye et al. (2025). “Black-Box On-Policy Distillation of Large Language Models.” (ArXiv 2511.10643) Introduces Generative Adversarial Distillation (GAD) for distilling from a teacher whose internals are inaccessible. The student (generator) is trained on-policy and a learned discriminator rewards student outputs that resemble the teacher’s text. This discriminator serves as a learned on-policy reward model. GAD consistently outperforms sequence-level KD: e.g. a 14B student distilled against GPT-5-Chat teacher matches the teacher’s QA performance[11][12]. Relevance: Directly on-policy, tackles the black-box case. High priority: novel approach, strong results. (Priority: HIGH.)
Zhao et al. (2026). “Self-Distilled Reasoner: On-Policy Self-Distillation for LLMs.” (ArXiv 2601.18734) Proposes OPSD: the model trains itself with privileged reasoning traces. A single LLM serves as both teacher and student: the teacher policy conditions on gold chain-of-thought or scratchpad (privileged info), while the student policy sees only the original question. The student samples its own outputs on-policy, and the KL between teacher and student distributions is minimized per-token[13]. This requires no separate large teacher model beyond one LLM instance. They show 4–8× better token efficiency than RL (and better than offline KD). Relevance: Directly on-policy self-distillation (rich connections to GKD and context distill). Medium priority: novel framing, but similar to Shenfeld et al.’s SDFT. (Priority: MEDIUM.)
Cai & Yuan (2026). “$\mathcal{X}$-KD: General Experiential Knowledge Distillation for LLMs.” (ArXiv 2602.12674) A general framework where the student imitates not only teacher outputs but also the teacher’s learning environment. They model the teacher’s original reward function (via AVRIL inverse RL) and include this reward in distillation. This “experiential KD” yields a reward-regularized KD that encourages the student to behave consistently with the learned reward model. It is agnostic to model family and to token vs sequence KD. Empirically, $\mathcal{X}$-KD outperforms standard KD and MiniLLM on summarization, translation, and arithmetic[14]. Relevance: Tangential but interesting: bridges distillation with IRL to capture teacher rationale. (Priority: MEDIUM.)
Zhang et al. (2026). “Reinforcement-aware Knowledge Distillation for LLM Reasoning.” (ArXiv 2602.22495) Also called RL-aware Distillation (RLAD). They note that naive KL-based KD can clash with RL. Their solution is selective imitation: only imitate (apply teacher KL) when it would improve the student’s policy update. Concretely, they replace the KL loss with a trust-region-like likelihood ratio objective anchored to a teacher+old-policy mixture (PPO/GRPO style). This yields advantage-aware distillation that balances reward and imitation naturally. RLAD outperforms offline KD, standard GRPO, and fixed-KL OPD on reasoning benchmarks. Relevance: Directly aims to improve on-policy distillation by addressing objective interference. High priority, as it shows how to blend imitation with RL in OPD[15]. (Priority: HIGH.)
Xiong et al. (2026). “OVD: On-Policy Verbal Distillation.” (ICML 2026) Key idea: avoid expensive token-level supervision by using trajectory-level verbal feedback. Instead of matching full logits, the teacher gives each generated output a discrete “verbal score” (0–9) for reasoning correctness. The student then learns via policy optimization to maximize these scores. This drastically reduces memory and removes token alignment constraints, allowing freer exploration. On Q&A and math tasks, OVD yields large gains (+12.9% EM on web QA, +25.7% on math[16]). Relevance: Direct on-policy method that shifts from logit-KL to reward signals via teacher judgment. High priority: novel approach to the KL memory bottleneck, strong empirical results[17][16]. (Priority: HIGH.)
Other new finds: No other major OPD papers were found in Mar 2025–Mar 2026 beyond the above. We did not find further distinct methods under those queries.
3. Foundational Lineage
DAgger (Ross et al., 2011) – Introduces Dataset Aggregation for imitation learning. The learner iteratively collects data by following its own policy and queries an expert (teacher) for corrections. This eliminates train-test distribution mismatch by training on the student’s on-policy states[18]. In OPD, this principle underlies training the student on its own rollouts with teacher feedback (as in GKD and ImitKD).
SeqKD (Kim & Rush, 2016) – “Sequence-level Knowledge Distillation” for sequence models. The teacher generates synthetic output sequences, and the student is trained on these with standard cross-entropy. This yields much smaller models that retain teacher-level performance (e.g. 10× speedup in NMT with minimal loss)[19]. SeqKD is the classic off-policy KD baseline; OPD methods can be seen as on-policy extensions that continually generate sequences with the current student instead of a fixed synthetic corpus.
Born-Again Networks (Furlanello et al., 2018) – Showed that a student with the same architecture as its teacher can often surpass the teacher, by distilling iteratively (“born again”). They do this by treating the teacher’s outputs as soft labels. This foreshadows OPD’s reward extrapolation: knowledge distillation need not cap student performance at the teacher, a fact exploited later by ExOPD[10].
RL^2 (Duan et al., 2016; Wang et al., 2016) – “Fast Reinforcement Learning via Slow Reinforcement Learning.” Proposes meta-RL by training an RNN policy across tasks: the network learns to use its hidden state (past observations/rewards) to adapt quickly, effectively learning an RL algorithm. While not a distillation paper per se, RL^2 introduced the idea of treating sequences of actions (and the feedback) as data for meta-learning. OPD is analogous: the student policy is updated based on sequences of student actions and teacher feedback (or rewards), reminiscent of meta-learning on trajectories.
Learning Using Privileged Information (LUPI; Vapnik & Vashist, 2009) – A learning framework where, at training time, a teacher provides extra “privileged” features unavailable at test time. For example, an SVM+ uses teacher-provided hints to regularize learning. In OPD, the teacher often has privileged information (e.g. full vocabulary logits, chain-of-thought) while the student does not. OPD methods can be viewed as applying LUPI: distilling from teacher’s privileged outputs into the student’s parameters[20].
Hindsight Experience Replay (HER; Andrychowicz et al., 2017) – A technique for sparse-reward RL in which failed trajectories are relabeled as if they solved a different goal that matches the achieved outcome, turning failures into successes. Analogously, some OPD approaches (e.g. POPE, Nudging) relabel or augment training instances (with hints or new goals) to yield non-zero signal. HER’s core insight – learning from “what actually happened” – parallels using teacher feedback on student rollouts (even wrong ones) to drive learning.
4. Landscape Summary
Total papers: We have identified roughly 20–25 relevant works in OPD/self-distillation of LLMs (7 core papers already noted + ~13 new ones above + foundational). The pace has accelerated in 2025–26, with many arXiv preprints in Jan–Feb 2026.
Clusters/subfields: Emerging clusters include:
On-policy vs off-policy KD: OPD (student samples its own outputs) vs SeqKD.
Teacher setups: Large separate teacher (GKD, MiniLLM, GAD) vs self-teaching (OPSD, SDFT).
Loss formulations: KL-based policy gradient (GKD, MiniLLM), GAN/adversarial (GAD), trajectory-level scoring (OVD), variational inference (Zhou), reward scaling (Yang).
Use of privileged info: CoT/context as privileged signals (Context Distill, OPSD, POPE), self-generated hints (Nudging).
RL integration: Distillation combined with RL objectives (RLAD, ExOPD), or replacing RL entirely (OPD as cheap alternative).
Black-box distillation: When teacher logits are unavailable (GAD).
Open problems: Key challenges noted across the literature:
Credit assignment variance: Policy-gradient KD can have high variance. Many papers (e.g. MiniLLM, OVD) modify the objective to stabilize (reverse-KL, trajectory rewards) or reduce memory.
Balance of reward vs imitation: As RLAD and Yang et al. show, naive KL can compete with reward maximization. How to properly weight teacher signals? Reward extrapolation (ExOPD) is one answer, but general principle is unsettled.
Use of privileged data: How best to incorporate known answers or rationales? Context Distillation and OPSD show models can learn from them, but general protocols (e.g. how to generate them) are open.
Compute/data efficiency: While OPD can be cheaper than RL, it still requires many rollouts. Determining minimal samples, curriculum strategies, and robust baselines (like Feedback Descent) remains work to do.
Theoretical understanding: Except for a few (e.g. OPD=RL), a unified theory is lacking. The variational view is a step, but we lack guarantees on convergence or when on-policy strictly dominates off-policy.
Contradicting “on-policy is always better”: A few papers nuance the claim that on-policy = best. For example, RL-aware distillation (Zhang et al.) finds that applying KL imitation unconditionally can hurt learning; sometimes limiting it (trust-region constraints) is necessary. Yang et al. show on-policy distillation need not lock the student to teacher performance – with reward scaling, students can surpass teachers, which suggests pure on-policy KL might be too conservative. Conversely, some tasks may still benefit from off-policy methods when teacher guidance is strong or easy (context distillation essentially is offline/self-distillation with fixed teacher). Overall, the narrative is shifting from “on-policy beats off-policy” to “on-policy is powerful but must be applied carefully.”
5. Recommended Reading List
Xiong et al., On-Policy Verbal Distillation (ICML 2026). Introduces OVD, which replaces token-level KD with discrete trajectory scores, drastically cutting memory and improving results. A novel and efficient twist on OPD[17][16]. (Priority: HIGH)
Ye et al., Black-Box On-Policy Distillation (ArXiv 2025). Proposes Generative Adversarial Distillation for on-policy KD without teacher logits[11]. Important for cases where teacher internals are hidden. (HIGH)
Zhang et al., Reinforcement-aware KD (ArXiv 2026). RLAD (ICLR 2026) – an on-policy distillation method that replaces simple KL with a PPO-like trust-region loss, improving distillation-RL synergy. Shows how to blend imitation only when helpful[15]. (HIGH)
Cai & Yuan, Experiential KD (ArXiv 2026). Introduces $\mathcal{X}$-KD, using IRL to capture the teacher’s environment. A creative generalization of KD that outperforms MiniLLM baselines[14]. (MEDIUM)
Zhou et al., Variational Reasoning (ArXiv 2025). Presents a principled VI framework for reasoning (latent CoT)[9]. Although not strictly OPD, it unifies KD and RL views and yields stable forward-KL training, making it useful background. (MEDIUM)
